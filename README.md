# JavaScript DOM To-Do App

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript DOM manipulation.

## Overview

This project allows users to manage their daily tasks through a simple and user-friendly interface. It demonstrates how JavaScript DOM methods can dynamically create, update, and remove HTML elements.

## Features

- Add new tasks.
- Add tasks using the Enter key.
- Mark tasks as completed.
- Undo completed tasks.
- Delete individual tasks.
- Input validation to prevent empty tasks.
- Responsive user interface.

## Technologies Used

- HTML5 – Page structure.
- CSS3 – Styling and responsive design.
- JavaScript – DOM manipulation and event handling.

## DOM Concepts Practiced

- `getElementById()`
- `createElement()`
- `appendChild()`
- `addEventListener()`
- `classList.toggle()`
- `remove()`
- `innerText`
- `value`
- Keyboard events (`keydown`)

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start adding and managing your tasks.
